# `platform` — what differs between the platforms cjls runs on

A multiplatform module ([D101](../../docs/adr/0101-platform-code-is-a-multiplatform-module.md), C17): one package, `platform`, over the source sets `cjpm.toml` names, chosen by the host's `os.*`. `src/common` holds the API, `common` declarations without bodies, and what is written once on them (`StdinStream`, `PipedChild`, `ChildPipes`); `src/posix` (`@NonProduct`, what macOS and Linux share: `os.linux` and `os.darwin` map to `user.platform.posix`), `src/linux`, `src/darwin` and `src/windows` give the `specific` bodies. Each file starts with its set's header (`features { user.platform.posix, os.linux }`; `@NonProduct features {…}` in a non-product set), and is named for what it holds (`posix/stdio.cj`), its directory naming the set (D113).

- **A test is in a product set** (`linux`, `darwin`, `windows`): one in `common` or `posix` is neither compiled nor run, and cjpm says nothing. What `common` code does is tested by the modules calling it.
- **Another platform is type-checked here**: `cjpm build -m modules/platform --no-feature-deduce --enable-features=os.windows` (`os.darwin`); only that OS's CI runs its tests.
- **`build.cj` copies the product up**: `cjpm test` of a module using `platform` looks for `libplatform.a` and `platform.cjo` in `<target>/<profile>/platform/`, not in the product set's `src/<set>/product/`, and neither imports nor links them otherwise; after each build the script copies them there, in every directory under `target` (cjpm tells it no `--target-dir`), and removes them before each build: `cjpm build` takes such a copy before the product, and one older than it (CI's `target` restored from master) compiles a module using `platform` against its old API.
- **`-O1`** (D102): at `-O2` the common part puts the std functions it calls into the library, and the link fails.
- **A constant is a function** (`hostOs()`): a `common let` wants its `specific` in the very next set, `posix`. A `specific` function warns of a parameter it does not use, where a plain one does not: `-Woff unused` (D97) silences it, as it does everywhere.
- **The architecture is `@When[arch == …]`** (`hostArch`, in `common/os.cj`), the one `@When` of the repository's code (D113): cjpm deduces a feature of `os.*` alone, and Linux is to be built for two. `WhenGateTest` (`project_model`) fails on any other, a test of `platform` included.
- **Windows** is Win32 through FFI: `CreateProcessW` for a child on two inherited pipe handles, suspended until it is in a kill-on-close job (`KillOnCloseJob`, D78, D91); `relaunch` runs the server again as a child after `tieChildrenToThisProcess`. No foreign function that blocks is `@FastNative` or named like a libc function (C5).
